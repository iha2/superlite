 ------------------------------------------------------------------------------
  HOW A BUILD RUNS

   you ask --> Opus plans --> [you approve] --> lint --> parallel build --+
                              (human mode)    (gate)   Haiku first,       |
                                                       Sonnet the rest    |
   report <-- fixes by tier <-- final review <-- background tests <-------+
   (time, cost,                 (one fresh        (never block the
    projected vs actual)         reviewer)         coordinator)

   Nothing is committed unless you ask: work is kept as hidden checkpoints.
 ------------------------------------------------------------------------------
  START                                     WHO DECIDES
   /superlite:start [mode] [what]  menu       /superlite:human   you approve the
   /superlite:mvp <what>   prototype first                       plan first
   /superlite:feature <change>  existing code /superlite:ai      hands off
   /superlite:debug <bug>  root cause first   /superlite:approve [plan]  go
   /superlite:small <change>  inline, quick

  DURING A BUILD                            AFTER
   /superlite:status   where it stands        /superlite:review [branch]
   /superlite:sessions list/switch/discard    /superlite:report [plan] [full]
   /superlite:stop     stop dispatching       /superlite:commit  checkpoints
   /superlite:resume   pick up again                             -> commits
   /superlite:agents   the agent map          /superlite:finish  merge or PR,
   /superlite:tail     live feed (no mod)                        never pushes
  SETUP
   /superlite:setup    first-run check
